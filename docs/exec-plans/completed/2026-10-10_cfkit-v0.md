## Objective

The repository-local harness, v0: a typed `cfkit` CLI (TypeScript run natively by Node 22's type stripping — zero runtime dependencies) providing `verify --profile fast|full` with a single typed profile registry, `budget:check` delegating to the existing script, and a read-only `doctor`. `npm run verify` delegates to the fast profile; CI runs the full profile through `verify:ci`.

## Constraints

- TypeScript with `erasableSyntaxOnly` (no enums/namespaces) so `node tools/cfkit/cli.ts` executes directly — verified empirically on Node 22.22 before committing to it; `@types/node` is the only added devDependency (for the typecheck step).
- Profiles are data in one registry (`tools/cfkit/profiles.ts`); every step id must exist as an npm script — a test enforces the wiring.
- The runner is fail-fast with an injectable step executor so order, stop-on-failure, and exit-code propagation are fixture-testable (gate honesty).
- `budget:check` delegates to `scripts/budget/check.mjs` (single implementation); `doctor` gathers facts and evaluates them as pure functions (node/.nvmrc agreement, dependencies, wrangler config, budget script, migrations dir) and changes no state.
- `.mjs`-era tooling stays untouched; the harness is `tools/cfkit/**` (family naming).
- Profiles: `fast` = format:check, lint, typecheck, typecheck:cfkit, test, test:scripts, budget:check (no bundling — backend precedent); `full` = fast + build (dry-run). `npm run verify` → fast; `verify:ci` → full; CI's verify step switches to `npm run verify:ci`.
- Strict lint budgets (ADR-0011); no comments.

## Acceptance Criteria

1. `npm run cfkit -- verify --profile fast` runs the fast steps fail-fast with per-step timings; a failing step stops the run and propagates the exit code.
2. `npm run verify` delegates to the fast profile; `npm run verify:ci` runs full (fast + build); CI invokes `verify:ci`.
3. `npm run cfkit -- doctor` prints ok/warn/fail checks and exits non-zero only on failures.
4. `npm run cfkit -- budget:check` delegates to `scripts/budget/check.mjs` and passes.
5. Fixtures cover: profile membership, registry-vs-package.json wiring, runner order/fail-fast/exit codes, doctor evaluations (golden vs broken facts).
6. Everything green; roadmap 1.11 checked; plan filed to `completed/`.

## Completion Notes

cfkit v0 landed as typed TypeScript under `tools/cfkit/` (Node 22 native type stripping; `erasableSyntaxOnly` enforces compatibility; only `@types/node` added). `profiles.ts` is the single registry (fast: format:check, lint, typecheck, typecheck:cfkit, test, test:scripts, budget:check; full: + build), with a fixture asserting every step id exists as an npm script. `runner.ts` runs fail-fast with injectable execution (order, stop-on-failure, and exit-code propagation fixture-tested); `doctor.ts` evaluates gathered facts as pure functions; `cli.ts` dispatches verify / budget:check / doctor with exit codes. `npm run verify` delegates to fast; CI now runs `npm run verify:ci` (full). Lint surfaced real gaps fixed en route: scoped `no-console` allowlist for the CLI, `no-floating-promises` exception for `node:test` registration, and an optional-chain nit. 7 new fixtures (13 script fixtures total); fast and full profiles verified live; doctor and delegation verified live.

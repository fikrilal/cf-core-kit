# Database Seam (task 1.6)

- Status: completed
- Owner: fikrilal
- Risk: medium
- Date: 2026-10-10
- Related ADRs / proposals: ADR-0004 (D1 + Drizzle, batch semantics), ADR-0008 (platform boundaries), ADR-0005 (write discipline); roadmap task 1.6

## Objective

The D1 seam every repository rides on: the `DB` binding wired through wrangler and generated `Env` types, a typed Drizzle client factory, the schema root, a batch helper that expresses the ADR-0004 transaction invariant (multi-statement atomicity via `batch()`; no interactive transactions across awaits), and the migrations pipeline wiring (`drizzle-kit generate` → `wrangler d1 migrations apply`). Tests run against the local D1 that the Workers test runtime provides.

## Constraints

- ADR-0004: D1 only; migrations committed and reviewed once they exist; no runtime DDL.
- Binding access stays inside `src/platform/db` (ADR-0008); features receive ports later.
- The schema root starts empty — the first table (and therefore the first migration) lands with task 1.7; no speculative tables.
- Local-only placeholder `database_id`; the real id is set in the deployment phase (1.13). Remote commands are out of scope here.
- Strict lint budgets (ADR-0011); no comments.

## Impact Areas

- API / contract: no
- DB / migrations: yes (client seam, batch semantics, pipeline wiring)
- Auth / session: no
- Queue / jobs: no
- Config / secrets: no (the binding is not parsed by the config module)
- Observability: no
- Budget / free-tier footprint: yes (write discipline context; batch = one round trip)
- CI / release: no (drift checks join 1.12)

## Acceptance Criteria

1. `wrangler.jsonc` declares the `DB` D1 binding and `migrations_dir`; `wrangler types` regenerates `Env` with `DB: D1Database`.
2. `createDb(binding)` returns a Drizzle client bound to the schema root; the batch helper preserves Drizzle tuple typing and maps to `db.batch`.
3. Tests against local D1: Drizzle insert/select round-trip, batch atomicity (one failing statement applies none), and a `select 1` sanity query.
4. `db:generate` and `db:migrate:local` scripts are wired; `wrangler d1 migrations apply --local` smoke passes (empty set until 1.7).
5. Tests green; `npm run verify` green; roadmap 1.6 checked; plan filed to `completed/`.

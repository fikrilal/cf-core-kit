# Guides

Task-oriented walkthroughs that mirror the `cfkit` tooling. Standards live in
`docs/standards/`; these guides show the commands and the shape of the output.

| Guide                                            | Use it when                       |
| ------------------------------------------------ | --------------------------------- |
| [adding-a-feature.md](./adding-a-feature.md)     | Starting a new feature slice      |
| [adding-an-endpoint.md](./adding-an-endpoint.md) | Implementing a contract operation |
| [config.md](./config.md)                         | Adding or reading configuration   |
| [jobs.md](./jobs.md)                             | Adding background work            |

Everything the tools refuse is refused for a reason; each guide lists the refusals it can hit.
